# SKAY Industries — Architectural Windows & Doors Website

Official website for **SKAY Industries**, manufacturers and fabricators of premium uPVC and Aluminium window and door systems.

## 🚀 Features

- **Full-Bleed Architectural Hero Carousel**: High-impact visuals with slide controls, indicators, and touch support.
- **Brochure-Accurate Content**: 12+ window typologies (Casement, Sliding, Tilt & Turn, Fixed, Bay, Arch, Louver, and more).
- **Interactive Sidebar Navigation**: Clean drawer navigation with quick jump links (Home, About, Projects, Location, Enquiry).
- **Color Palettes & Profile Options**: Realistic wood finishes and solid architectural tones.
- **Responsive & Modern Design**: Clean typography with Playfair Display and Plus Jakarta Sans, optimized for mobile, tablet, and desktop screens.
- **Direct Enquiry & Contact Integration**: Interactive booking form and WhatsApp/call click-to-contact links.

## 📁 Project Structure

## 🌐 Deploy to Vercel

### Option 1: Vercel Dashboard (Recommended)
1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **"Add New..."** -> **"Project"**.
3. Import your GitHub repository: `https://github.com/Falkiya/Skay_-Industry-.git`.
4. Click **"Deploy"** (no build settings required — it automatically deploys as a static website).

### Option 2: Vercel CLI
```bash
npx vercel
```
Follow the interactive prompts to link and deploy to production.
